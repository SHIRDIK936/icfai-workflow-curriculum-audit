# TASK 2: CURRICULUM AUDIT AND REDESIGN

## 1. Introduction

**Institution:** ICFAI Tech, Hyderabad  
**Programme:** B.Tech Artificial Intelligence and Machine Learning  
**Admission Batch:** 2023–2027  
**Review Date:** 24 October 2026

This report reviews the existing AI/ML curriculum and proposes improvements to strengthen technical knowledge, practical experience, and industry readiness.

The review uses the curriculum table in the ICFAI Tech Student Handbook 2023–24, Section 4.7.3, page 27, together with selected industry job descriptions.

## 2. Objectives

The objectives are to:

1. Map the existing courses and credits semester-wise.
2. Identify important foundational courses to retain.
3. Recommend updates to selected technical subjects.
4. Propose reductions where specialized material could be reorganized.
5. Introduce practical topics relevant to modern AI development.
6. Compare curriculum coverage against three dated job descriptions.
7. Evaluate five proposed AI-assisted learning exercises.
8. Design a practical laboratory based on Task 1.

## 4. Curriculum Redesign

The recommendations are grouped into four categories.

### KEEP

Retain core subjects such as Computer Programming, Data Structures, Design and Analysis of Algorithms, and foundational Mathematics.

These subjects support programming ability, problem-solving, algorithm design, and mathematical understanding.

### UPDATE

Strengthen practical content in:

- Database Management Systems
- Artificial Intelligence
- Data Science
- Machine Learning
- Data Wrangling and Visualization
- Deep Learning
- Big Data Systems
- Special Project

Suggested improvements include automated testing, reproducible experiments, practical data pipelines, model evaluation, and technical documentation.

### REDUCE

Consider reducing compulsory coverage in selected specialized subjects, including Blockchain Technology and Autonomous Vehicles.

These reductions are proposals and require faculty review. Essential existing learning outcomes should be preserved.

### ADD

Introduce practical coverage of:

- Responsible AI and model evaluation
- MLOps and model deployment

The proposed change register transfers two credits from selected specialized subjects to these new topics, producing a net change of zero credits within the listed changes.

## 5. Credit Impact

The proposal preserves the recorded 135 credits across Semesters I–VI at the aggregate level.

The change register identifies 27 affected credits, corresponding to 20% of that six-semester baseline.

This percentage is **not** the percentage of the complete programme because the final-year credit allocations have not been reconciled.

The proposed changes are documented in `proposed_curriculum.csv`.

## 6. Industry Job Comparison

Three dated Amazon job descriptions were selected for comparison.

The analysis identifies recurring requirements involving programming, machine learning, deep learning, large-scale data processing, experimentation, and model development.

The comparison supports improving practical assignments and deployment-oriented skills.

The complete comparison, including job IDs and links, is provided in `job_comparison.md`.

These postings represent one employer and include roles with different experience requirements.

## 7. AI-Assisted Exercises

Five proposed AI-assisted exercises cover:

1. Computer Programming
2. Data Structures
3. Database Management Systems
4. Machine Learning
5. Deep Learning

The reference implementations passed five automated checks.

The checks validate prepared reference solutions and expected outcomes. They do not demonstrate that actual AI-generated responses were collected and evaluated.

Exercise prompts, expected outputs, verification methods, and limitations are documented in `ai_exercises.md`.

The executable checks are provided in `test_ai_exercises.py`.

## 8. Proposed Practical Laboratory

A database laboratory is proposed using the hypothetical College Lab Booking and Approval System from Task 1.

Students would design database tables, implement booking rules, enforce authorization, and test five exceptional and normal scenarios.

The laboratory proposal is documented in `lab_design.md`.

## 9. Expected Benefits

The proposed changes aim to:

- Strengthen practical programming and AI skills.
- Improve familiarity with model evaluation and deployment.
- Encourage independent verification of AI-generated answers.
- Connect database theory with realistic workflow design.
- Improve project documentation and testing practices.

These are expected benefits, not measured outcomes.

## 10. Limitations

The review is limited by:

- Unresolved official credit discrepancies.
- Incomplete verification of the final-year curriculum allocations.
- Job descriptions from a single employer.
- Lack of recorded faculty or graduate validation.
- No classroom implementation of the proposed laboratory.
- No recorded actual AI-generated responses for the five exercises.

## 11. Conclusion

The existing AI/ML curriculum contains important foundations in mathematics, programming, algorithms, machine learning, and deep learning.

The proposed redesign emphasizes practical implementation, model deployment, responsible AI, and software testing while retaining those foundations.

The recommendations remain provisional until the official credit structure and relevant academic approvals are confirmed.
