# Curriculum Analysis and Redesign Recommendations

## 1. Programme Information

- **Institution:** ICFAI Tech, Hyderabad
- **Programme:** B.Tech in Artificial Intelligence and Machine Learning
- **Admission Batch:** 2023–2027
- **Curriculum Source:** ICFAI Tech Student Handbook 2023–24, Section 4.7.3, page 27
- **Review Date:** 24 October 2026

## 2. Purpose

This analysis reviews the existing AI and Machine Learning curriculum and proposes improvements that strengthen industry readiness, practical learning, software engineering, and responsible AI development.

The recommendations are proposals rather than officially approved curriculum changes.

## 3. KEEP Recommendations

**KEEP 1 — Data Structures**

Data Structures should remain a core subject because students need efficient data organization and algorithmic problem-solving skills for technical interviews and software development.

**KEEP 2 — Design and Analysis of Algorithms**

Algorithms should remain compulsory because computational efficiency is essential for processing large datasets and developing scalable applications.

**KEEP 3 — Linear Algebra and Probability**

Mathematics provides the foundation for machine learning models, optimization, neural networks, and statistical reasoning.

## 4. UPDATE Recommendations

**UPDATE 1 — Machine Learning**

Add practical exercises covering model evaluation, cross-validation, data leakage, experiment tracking, and reproducibility.

**UPDATE 2 — Deep Learning**

Include hands-on activities using modern deep learning frameworks, pretrained models, and model optimization.

**UPDATE 3 — Database Management Systems**

Expand laboratory activities to include SQL optimization, data pipelines, and introductory vector-search concepts.

**UPDATE 4 — Data Wrangling and Visualization**

Introduce reproducible data-cleaning workflows, data-quality checks, and dashboard development.

## 5. REDUCE Recommendations

**REDUCE 1 — Blockchain Technology**

Consider reducing compulsory coverage of specialized blockchain topics and moving advanced material into an elective. Preserve essential concepts where relevant.

**REDUCE 2 — Repetitive Introductory Coding Content**

Review introductory coding modules for overlap. Replace repeated beginner exercises with integrated projects, without weakening programming fundamentals.

## 6. ADD Recommendations

**ADD 1 — MLOps and Model Deployment**

Introduce version control for datasets and models, model serving, monitoring, and deployment pipelines.

**ADD 2 — Responsible AI and Model Evaluation**

Teach bias testing, privacy, explainability, model documentation, and responsible deployment practices.

**ADD 3 — AI Software Engineering Capstone**

Require students to build and evaluate a working AI application with testing, documentation, and a deployment plan.

## 7. Summary

These recommendations preserve essential computer science and mathematical foundations while emphasizing practical AI development.

The final redesign must verify official course credits, demonstrate the required credit balance, and use evidence from at least three dated job descriptions before recommendations are considered validated.

## 8. Evidence and Limitations

The semester-wise course mapping is recorded in `official_curriculum.csv`.

The handbook transcription contains unresolved credit-total discrepancies, particularly in the final-year grouped allocations. Therefore, this analysis does not claim that a credit-balanced redesign has already been established.

No faculty approval, graduate interview, or employer validation is claimed.
